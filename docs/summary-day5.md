# Day 5 总结（2026-08-11）

## 学了什么
- **UART 是什么**：异步串行通信——**没有时钟线**，只有一根数据线，靠约定波特率对齐节奏（对比 SPI/I2C 有同步时钟线）
- **一帧格式（8N1）**：空闲高电平 → **起始位 1（低）** → **数据位 8（低位在前）** → **停止位 1（高）** = **10 bit**；校验位可选（8E1/8O1 才 +1 位变 11）
- **波特率**：每秒传多少 bit；115200 波特 = 每 bit 1/115200 ≈ 8.68μs
- **波特率发生器原理**：50MHz/115200 = 434.03 → 数 **0~433** 共 434 个周期，数满清零 + 出 1 个时钟周期宽的窄脉冲
- **实际波特率**：50M/434 = **115207 bps**，误差 **(115207−115200)/115200 ≈ 0.006%**，远小于 ±2~3% 容忍线
- **$finish vs $stop**：$finish 终止整个仿真（always 时钟是无限循环，不写它仿真永远跑）；$stop 只暂停可继续
- **`timescale**：时间单位/精度声明，`1ns/1ps` 下 `#10` = 10ns；没有它仿真器不知道时间单位
- **层次引用**：TB 里 `u_uart_baud.cnt` 直接看被测模块内部信号

3. **时序逻辑混用阻塞赋值**：`=` 混进 always 时序块（第 4 天老坑重现，必须全 `<=`）

## 感悟
- **波特率发生器 = 翻译官**：把「秒」翻译成「时钟周期」——系统时钟太快要数周期，数够了才翻一下。第 6 天 UART TX 拿它的脉冲当「节拍器」
- **证据链比肉眼可靠**：游标量出 8708ns vs 理论 8680ns 差 28ns 时，一度以为电路错了；但 cnt=330（2500 mod 434）分毫不差，证明是点击精度问题。**波形 + 计数器数学 + Transcript 时间戳，三证据交叉**
- **数 0~433 共 434 个**：从 0 开始数这个细节最容易错——「数满 434 个周期」和「计数到 434」是两回事
