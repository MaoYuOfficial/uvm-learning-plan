## 踩的坑（重点）
1. **位宽扩展**：`b ^ sub` 中 1 位的 sub 会零扩展成 000...001，只取反 b 的 bit0！
   正确：`b ^ {32{sub}}` 或 `sub ? ~b : b`
2. **reg 位宽放反**：`reg [15:0] x` 是 16 位向量，`reg x[15:0]` 是 16 个 1 位数组
3. **化简后必须验证**：用真值表逐行核对（今天化简全加器翻车 2 次）
4. **运算符优先级**：`+`（算术加）优先级比 `|` 高，`a|(b^cin)+b|cin` 被解析成 `a|((b^cin)+b)|cin`，拿不准就加括号
5. **assign 驱动 wire，always 赋值 reg**：看到赋值方式就知道声明什么

## 关键公式
- 全加器：sum = a ⊕ b ⊕ cin；cout = ab + ac + bc = a(b⊕c) + bc
- 加减法器：a - b = a + ~b + 1（b 异或 sub 取反，cin 接 sub）
- 德摩根：~(A&B) = ~A + ~B；~(A|B) = ~A · ~B
- 吸收律：x + x'y = x + y

- 进位选择加法器：为什么叫"进位选择"？
普通的 32 位加法器，进位要从最低位一路传到最高位（串行，慢）。进位选择加法器的思路是：高位的结果提前把两种可能（进位 0/1）都算好，两个加法器并行算，等低位的进位一到，瞬间"选"一个——用"选择"代替"传播"，速度快一倍。

用空间（多一个加法器）换时间（不用等进位爬）——这就是"面积换速度"，芯片设计的永恒主题。
